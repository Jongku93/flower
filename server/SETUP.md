# 함께 보는 순위 — 설치 (약 5분, 한 번만)

게임은 GitHub Pages 에 있고, 점수는 **선생님 개인 구글 시트**에 모입니다. 무료이고 광고·회원가입이 없습니다.
(학교용 Apps Script 와는 따로, 개인 구글 계정으로 만드세요.)

1. 컴퓨터에서 **https://sheets.new** 를 열어 새 구글 시트를 만들고, 이름을 `꽃정원 순위` 로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 열린 편집기의 `Code.gs` 내용을 모두 지우고, 아래 파일 내용을 통째로 붙여 넣은 뒤 💾 저장합니다.
   https://raw.githubusercontent.com/Jongku93/flower/main/server/leaderboard.gs
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴(유형 선택) → **웹 앱**
   - 설명: `꽃정원 순위`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 검토 → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**
   (내가 만든 스크립트라서 나오는 안내입니다. 이 스크립트는 이 시트에만 씁니다.)
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서 Claude 에게 보내 주세요.
   또는 직접: GitHub 저장소 **Settings → Secrets and variables → Actions → Variables → New repository variable**
   이름 `LEADERBOARD_URL`, 값 = 그 주소 → **Actions → GitHub Pages → Run workflow** 로 다시 배포.

## 관리

- 시트에 `scores` 탭이 생기고 한 판마다 한 줄씩 쌓입니다(시각·이름·점수·단계·꽃·턴·기기).
- 이상한 이름이나 기록은 **그 줄을 지우면** 순위에서 바로 빠집니다.
- 순위는 '기기 + 이름' 하나당 최고 점수만 셉니다.
- 서버 코드를 고치면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 해야 반영됩니다(주소는 그대로).

## 이미 막아 둔 것

- 이름 10자, 꺾쇠·제어문자 제거, 시트 수식(=…)으로 읽히지 않게 처리
- 터뜨린 꽃 수에 비해 말이 안 되는 점수 거절
- 같은 기기에서 8초 안에 연달아 보내면 거절
- 게임 쪽: 같은 판을 두 번 올리지 않음, 인터넷이 끊기면 모아 두었다가 연결되면 보냄
